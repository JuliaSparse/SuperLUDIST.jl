mutable struct ReplicatedSuperMatrix{T, I, S, F, J, G} <: SuperLUDIST.AbstractSuperMatrix{T, I, S}

SuperMatrix that has been globally replicated on all ranks in a communicator. The local storage contains the full matrix, the Julia representation may be accessed by A.store::SparseBase.CSCStore{T, CIndex{<:Int}}.

SuperLUDIST.DistributedSuperMatrix — Type
mutable struct DistributedSuperMatrix{T, I, S, F, J, G} <: SuperLUDIST.AbstractSuperMatrix{T, I, S}

SuperMatrix distributed by row between all ranks in a communicator. The Julia representation may be accessed by A.store::SparseBase.CSRStore{T, CIndex{<:Int}}.

Each local matrix stores a subset of rows specified by A.globalrows

Extended

  • supermatrix: Internal: Reference to the C SuperMatrix

  • format: Internal: Reference to the C storage format NRformat_loc held by supermatrix

  • store: Julia-side storage, of type SparseBase.CSRStore. Keeps memory alive.

  • globalsize

  • first_row

  • grid

SuperLUDIST.cscstore — Function
cscstore(Tv, Ti, A)

Copy the sparse matrix A (anything with SparseMatrixCSC's colptr, rowval and nzval fields, such as the result of MatrixMarket.mmread) into a SparseBase.CSCStore with the 0-based CIndex{Ti} indices that SuperLUDIST expects. The values are always copied, since SuperLUDIST may scale and permute the matrix in place.

LinearAlgebra.lu! — Method
lu!(A::Union{ReplicatedSuperMatrix, DistributedSuperMatrix}, b_local = ones(...); kwargs...)

Factorize A with SuperLU_DIST, and return a factorization object F that solves with F \ b or ldiv!(F, b). A distributed b holds this rank's rows of the right hand side.

On a Grid3D, later solves run in blocks of as many columns as b_local has, so pass a b_local with the number of right-hand sides you will usually solve with.

The keyword arguments are passed on to pgssvx!, for example options.

Configuration

SuperLUDIST.Grid — Type
Grid{Ti}(nprow, npcol, comm = MPI.COMM_WORLD; batch = false, usermap = nothing)

A 2D nprow × npcol process grid for SuperLU_DIST with index type Ti ∈ (Int32, Int64), built from the first nprow * npcol ranks of comm. MPI is initialized if necessary.

With batch = true the ranks are mapped onto the grid by usermap, a nprow × npcol matrix of ranks (default: row-major order).

Fields of the underlying gridinfo_t, such as iam, nprow and npcol, are available as properties.

source
SuperLUDIST.Grid3D — Type
Grid3D{Ti}(nprow, npcol, npdep, comm = MPI.COMM_WORLD)

A 3D nprow × npcol × npdep process grid for SuperLU_DIST's communication-avoiding 3D factorization, with index type Ti ∈ (Int32, Int64), built from the first nprow * npcol * npdep ranks of comm. It consists of npdep layers of nprow × npcol 2D grids. npdep must be a power of two. MPI is initialized if necessary.

A DistributedSuperMatrix on a Grid3D is solved with SuperLU_DIST's pgssvx3d drivers. Its rows must be distributed over all the ranks of the 3D grid.

Fields of the underlying gridinfo3d_t, such as iam, nprow, npcol, npdep, grid2d (this rank's layer) and zscp (zscp.Iam is the layer number), are available as properties.

SuperLUDIST.set_gpu! — Function
set_gpu!(gpu::Symbol)

Choose which build of SuperLU_DIST to use:

  • :none (the default) uses the CPU build from SuperLU_DIST_jll.
  • :cuda uses the CUDA build from SuperLU_DIST_CUDA_jll. That package is not installed with SuperLUDIST, so add it to your environment first. The CUDA build needs x86_64 Linux, an NVIDIA GPU and driver, and MPI.jl configured with MPItrampoline, and SuperLUDIST reports an error when it is loaded where it can't be used.

Libraries set with set_libraries! take precedence. HAVE_CUDA tells which build is in use.

The choice is stored with Preferences.jl and takes effect after restarting Julia.

source
SuperLUDIST.HAVE_CUDA — Constant
HAVE_CUDA

Whether SuperLUDIST is set up for a CUDA build of SuperLUDIST. With it, factorizations and solves are offloaded to the GPU unless `options.superluaccoffloadis set to 0. If the CUDA build can't be used where SuperLUDIST is loaded, an error is logged and the libraries are not set. See [setgpu!`](@ref).

source
SuperLUDIST.set_libraries! — Function
set_libraries!(; libsuperlu_dist_Int32 = nothing, libsuperlu_dist_Int64 = nothing)

Use your own builds of SuperLUDIST instead of the ones from `SuperLUDISTjllorSuperLUDISTCUDAjll, for example to link against a system MPI on an HPC cluster. The libraries must be SuperLU_DIST 9.3.x, built with 32-bit and 64-bitinttrespectively, and linked against the same MPI that MPI.jl uses. They may be CPU or CUDA builds, but both must be the same kind. Either may be omitted, in which case matrices with that index type are unavailable. Callingsetlibraries!()` with no arguments reverts to the jll builds.

The choice is stored with Preferences.jl and takes effect after restarting Julia.

MatrixMarket.mmread — Method
mmread(DistributedSuperMatrix{Tv, Ti}, filename::String, grid::AbstractGrid{Ti}; root = 0, partitioner = distribute_evenly)

Read an mtx file on rank root and distribute its rows between the ranks in grid. The grid must use all the ranks of grid.comm.

Arguments

  • arg1<:Type{DistributedSuperMatrix{Tv, Ti}}
    • Tv <: Union{Float32, Float64, ComplexF64}: Non-optional eltype.
    • Ti <: Union{Int32, Int64}: Non-optional index type.
  • filename::String: .mtx file accessible by the root process.
  • grid::AbstractGrid{Ti}: The 2D or 3D process grid on which to distribute the matrix.

Keyword Arguments

  • root::Int = 0: The MPI process on which to read the file.
  • partitioner = SparseBase.Communication.distribute_evenly: Computes the number of rows

on each rank from the number of rows and ranks.

Example

using MPI, SuperLUDIST, MatrixMarket
grid = SuperLUDIST.Grid{Int32}(2, 2)
A = MatrixMarket.mmread(DistributedSuperMatrix{Float64, Int32}, "matrix.mtx", grid)

MatrixMarket.mmread — Method
mmread(ReplicatedSuperMatrix{Tv, Ti}, filename::String, grid::Grid{Ti}; root = 0)

Read an mtx file on rank root into a compressed sparse column format and broadcast it to all ranks in grid.

Arguments

  • arg1<:Type{ReplicatedSuperMatrix{Tv, Ti}}
    • Tv <: Union{Float32, Float64, ComplexF64}: Non-optional eltype.
    • Ti <: Union{Int32, Int64}: Non-optional index type.
  • filename::String: .mtx file accessible by the root process.
  • grid::Grid{Ti}: The process grid on which to replicate the matrix.

Keyword Arguments

  • root::Int = 0: The MPI process on which to read the file.

Example

using MPI, SuperLUDIST, MatrixMarket
grid = SuperLUDIST.Grid{Int32}(1, 1)
A = MatrixMarket.mmread(ReplicatedSuperMatrix{Float64, Int32}, "matrix.mtx", grid)
